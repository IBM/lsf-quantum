# Contributing to LSF QPU plugins

**We appreciate all kinds of help, so thank you!**

## Development Environment
Setup a development environment following instructions in the [README](README.md)

## Contributing 
1. Fork the repository.
2. Create your feature branch: `git checkout -b my_new_feature`.
3. Add your changes and tests
4. Test everything.
5. Commit with a clear message.
6. Push and create a Pull Request.
   
### Reporting Bugs
When reporting bugs, please include:
1. A clear description of the problem.
2. Steps to reproduce.
3. Expected behavior.
4. Actual behavior.
5. Environment details.
   
### Requesting Features

Users are encouraged to use GitHub Issues for reporting issues and requesting features. Please provide:
1. A clear description of the feature.
2. The motivation for adding this feature.
3. Possible implementation ideas.

### Ask/Answer Questions 

Users are encouraged to use GitHub Discussions for engaging with researchers, developers, and other users regarding this quantum prototype and the provided examples.
